# API

The wire contract for the Algorithm Run Service, phase 1.

* [Run comparison endpoint](/api/run-comparison-endpoint.md) — `POST /v1/runs`.
* [Run retrieval endpoint](/api/run-retrieval-endpoint.md) — `GET /v1/runs/{run_id}`.
* [Error model](/api/error-model.md) — status codes and error body shape.
* [Worked example](/api/worked-example.md) — a complete request and its measured response.

Nothing here is implemented. This is the contract an implementation must satisfy, per
[the functional requirements](/requirements/functional-requirements.md).
